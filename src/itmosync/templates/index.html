Serverless сервис для расписания ИТМО в формате iCalendar

Твои персональные ссылки для подписки на iCalendar. Скопируй нужные ссылки и добавь их в свой календарь.

    {% for file in files %}
  • {{ file.emoji }} {{ file.name }}: {{ file.filename }} (Занятий: {{ file.count }})
    • {% endfor %}

Как подписаться?

Не скачивай файл (иначе он не будет обновляться). Скопируй ссылку и вставь её в настройки своего календаря по URL.
