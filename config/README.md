## ⚙️ Конфигурация

Ты можешь гибко настроить внешний вид событий, переименовать или исключать пары и многое другое. Для этого достаточно отредактировать необходимый `.yaml` файл:

### 1. [templates.yaml](templates.yaml)
Управляют тем, как события будут называться и выглядеть внутри твоего календаря.

**Доступные переменные:**
- `{title}` — название дисциплины
- `{type}` — тип занятия *(например, "Практические занятия")*
- `{label}` — метка для типа занятия
- `{format}` — формат проведения *("Очно", "Дистанционно" или "Смешанный формат")*
- `{teacher}` — ФИО преподавателя полностью *(если есть)*
- `{teacher_short}` — ФИО преподавателя кратко, формат: *Фамилия И. О.* *(если есть)*
- `{location}` — аудитория / место проведения *(если есть)*
- `{url}` — ссылка на пару *(если есть)*
- `{note}` — дополнительные примечания *(если есть)*

```yaml
templates:
  events:
    summary: "{label} {title} — {type}. {format}"
    description: "Преподаватель: {teacher}\n\n{note}"
    
  bookings:
    summary: "🗓️ Бронь: {title}"
    description: "{format}\n\n{note}"
```

### 2. [rules.yaml](rules.yaml)
Если ты хочешь убрать какие-то предметы из календаря или переименовать их, используй этот блок:

```yaml
rules:
  ignore:
    - "История России"              # Исключить весь предмет целиком
    - match: "Физическая культура"  # Исключить только очные занятия
      format: IN_PERSON
    - match: "БЖД"                  # Исключить только онлайн-лекции
      type: LECTURE
      format: REMOTE

  renames:
    - "Иностранный язык": "Английский"             # Переименовать предмет везде
    - match: "Архитектура вычислительных систем"
      type: LAB                                    # Переименовать только лабораторные
      format: IN_PERSON                            # и только если они очные
      to: "АВС (Лабы)"
```

### 3. [appearance.yaml](appearance.yaml)
Если тебе не нравится, как называются системные типы занятий или ты хочешь поменять метки, это делается здесь:

```yaml
appearance:
  type_names:
    LECTURE: "Лекция"
    PRACTICAL: "Практика"
    LAB: "Лабораторная"
    SPORT: "Спорт"
    EXTERNAT: "Экстернат"
    EXAM: "Экзамен"
    TEST_WITH_GRADE: "Диф. зачет"
    TEST: "Зачет"
    CONSULTATION: "Консультация"
    BOOKING: "Бронирование"

  labels:
    LECTURE: "📚"
    PRACTICAL: "🛠️"
    LAB: "🔬"
    SPORT: "🏃"
    EXTERNAT: "🎓"
    EXAM: "🔥"
    TEST_WITH_GRADE: "✨"
    TEST: "⭐"
    CONSULTATION: "🗣️"
    BOOKING: "🗓️"

  format_labels:
    2: "Очно"
    1: "Смешанный формат"
    3: "Дистанционно"
```

### 4. [system.yaml](system.yaml)
Здесь настраивается период выгрузки и поведение системных полей `LOCATION` и `URL` *(заполнять ли их нативно для iCalendar)*.

```yaml
system:
  fetch_start: "09-01"                      # С какого числа выгружать расписание
  fetch_end: "06-30"                        # По какое число выгружать расписание
  default_calendar_prefix: "ИТМО"           # Префикс названия календаря
  include_location: true                    # Системное поле локации
  include_url: true                         # Системное поле ссылки
```

### 5. [../.github/workflows/deploy.yml](../.github/workflows/deploy.yml)
По умолчанию расписание синхронизируется 4 раза в день. Если ты хочешь изменить это время, просто отредактируй этот файл в своем репозитории.
Найди блок `schedule:` и измени значение `cron`:
```yaml
  schedule:
    - cron: '17 3,9,15,20 * * *'  # Запускать в 03:17, 09:17, 15:17 и 20:17 UTC (соответствует 06:17, 12:17, 18:17 и 23:17 по МСК)
```
*Подробнее про синтаксис cron можно почитать на сайте [crontab.guru](https://crontab.guru).*

## 📖 Справочник значений

**Доступные форматы проведения (`format`):**
- `IN_PERSON` (или `2`) — Очно
- `HYBRID` (или `1`) — Смешанный формат
- `REMOTE` (или `3`) — Дистанционно

**Доступные системные типы пар (`type`):**
- `LECTURE` — Лекции
- `PRACTICAL` — Практические занятия
- `LAB` — Лабораторные занятия
- `SPORT` — Занятия спортом
- `EXTERNAT` — Экстернат
- `EXAM` — Экзамен
- `CREDIT` — Зачет
- `GRADED_CREDIT` — Дифференцированный зачет
- `CONSULTATION` — Консультация
- `BOOKING` — Бронирования
